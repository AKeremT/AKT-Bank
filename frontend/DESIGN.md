# AKT Bank — Design System & UX Principles

## Brand & Slogan
* **Brand Name:** AKT Bank
* **Slogan:** *"Simplicity in Every Step. Precision in Every Transaction."*

## Core UX Rules
1. **Zero Jargon for Everyday Users:** Replace intimidating ledger terms with friendly labels (`Add Money`, `Send Money`, `Money In (+)`, `Money Out (-)`), while keeping technical metadata (`Idempotency-Key`, `Reference ID`, `Role`) accessible in an optional developer section.
2. **Visual Account Selection:** Users never have to type 26-character IBANs manually; every money operation presents clickable visual account cards.
3. **Guided Step-by-Step Progression:** Clear numbered steps (`Step 1`, `Step 2`, `Step 3`) and an interactive **How It Works (Tutorial)** tab with 1-click live demo setup.
